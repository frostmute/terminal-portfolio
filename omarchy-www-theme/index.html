omarchy-www-theme — project your Omarchy theme onto omarchy.org

One Violentmonkey / Tampermonkey script + a tiny 127.0.0.1 bridge.
omarchy.org repaints in your current colors.toml — every omarchy theme set follows live, no repaste.

overview

omarchy.org ships a hard-coded Tokyo Night palette in root.css (--rgb-background-night, --rgb-terminal-blue...). This bridge reads your installed theme at ~/.local/state/omarchy/current/theme/colors.toml, converts it to those same CSS vars, serves it on http://127.0.0.1:17823/theme.css, and the userscript injects it at document-start. Result: omarchy.org looks like your desktop.

what it themes

omarchy.org background, text, links, buttons, borders, selection, scrollbars, code blocks — all from 6 vars in root.css:1. Images/video stay original.

Light themes (Catppuccin Latte, Flexoki Light, Lupine, White) auto set color-scheme: light.

what it doesn't touch

Your system theme. This is browser-only. `noctalia-sync.sh:1` / `stellarchy` themes keep working - this hook is independent.

Wallpaper is optional (disabled by default) - enable the commented body::before in the generated CSS if you want it.

quick start — 2 commands + 1 paste

Time: ~60 seconds. You do the install once; after that every omarchy theme set <name> auto-updates omarchy.org (refocus tab, no repaste).

1 — Install the bridge

Creates builder + server + hook + systemd service, builds CSS for your current theme, starts the localhost server.

curl -fsSL https://dirty.pizza/omarchy-www-theme/install.sh | bash

Verify: curl http://127.0.0.1:17823/theme.css | head should show /* Theme: neo-eldritch */ + systemctl --user status omarchy-org-theme-server → active.

2 — Install the userscript

Browser → Violentmonkey (recommended) or Tampermonkey / ScriptCat → use Install from URL (do not use xdg-open in terminal).

# ScriptCat: Dashboard → + → Import from URL
# Violentmonkey: Dashboard → + → Install from URL
# Tampermonkey: Dashboard → Utilities → Install from URL
https://dirty.pizza/omarchy-www-theme/omarchy.org.user.js
Install .user.js — click to trigger manager Get Violentmonkey Get ScriptCat

ScriptCat tip: don't run xdg-open URL in terminal — open the URL in the browser where ScriptCat is installed, or paste it into Import from URL. Tampermonkey will ask to allow 127.0.0.1 / localhost → Allow (needed for GM_xmlhttpRequest).

3 — Reload omarchy.org

Open https://omarchy.org → it should already be in your Omarchy colors. Try switching themes:

omarchy theme set catppuccin
omarchy theme set flexoki-light   # light theme demo
omarchy theme set neo-eldritch
# then alt-tab back to omarchy.org - it repolls on focus within 3s

DevTools → Console → filter omarchy-org shows [omarchy-org] applied neo-eldritch 2.6K. Check raw CSS at http://127.0.0.1:17823/theme.css and theme.json.

how it works

PiecePathRole
Builder~/.local/bin/omarchy-org-theme-buildPython: reads ~/.local/state/omarchy/current/theme/colors.toml (+ theme.name), hex→rgb, writes ~/.cache/omarchy-org/theme.css + theme.json + copies ~/.local/state/omarchy/current/background → ~/.cache/omarchy-org/background
Server~/.local/bin/omarchy-org-theme-server
~/.config/systemd/user/omarchy-org-theme-server.service		ThreadingHTTPServer on 127.0.0.1:17823 with Access-Control-Allow-Origin: * + no-store. Serves the cache dir. Started via systemctl --user enable --now.
Hook~/.config/omarchy/hooks/theme-set.d/99-omarchy-org-sync.shRuns after every omarchy theme set (like noctalia-sync.sh). Rebuilds CSS and ensures server is up.
Userscriptomarchy.org.user.js on omarchy.org/*GM_xmlhttpRequest fetches http://127.0.0.1:17823/theme.css at document-start, injects as <style id="omarchy-org-theme-bridge">, repolls every 3s while visible (15s hidden) + on visibilitychange/focus.
Mapping root.css → colors.toml: --rgb-background-night=background, --rgb-background-storm=lighter_bg, --rgb-terminal-black=muted, --rgb-terminal-blue=blue/accent, --rgb-terminal-cyan=cyan, --rgb-terminal-white=foreground, --rgb-turquoise=bright_cyan, --rgb-green=green. Light themes auto flip color-scheme.

why not pure Stylus / Stylish?

Blocked by browser security. omarchy.org is https. A Stylus @import url("http://127.0.0.1:17823/theme.css") is mixed active content and browsers block it. Same for file:/// imports. The userscript's GM_xmlhttpRequest runs in the extension context and bypasses both mixed-content and CORS — that's why this uses a userscript.

If you insist on Stylus: enable chrome://flags/#allow-insecure-localhost (Chrome) or use an https localhost with mkcert — not recommended. Use Violentmonkey.

optional — wallpaper on omarchy.org

Disabled by default (too noisy). The builder already copies your wallpaper to ~/.cache/omarchy-org/background and serves it. To enable:

nano ~/.cache/omarchy-org/theme.css
# uncomment the body::before block at the bottom:
# body::before { background: url("http://127.0.0.1:17823/background") center/cover ... }
# then tell the builder not to overwrite your edit, or edit the builder template:
nano ~/.local/bin/omarchy-org-theme-build  # remove the comment wrapping

Tip: lower opacity: 0.12 → 0.06 for subtler. Served as PNG/JPG sniffed from magic bytes.

troubleshoot & uninstall

common fixes

Stays Tokyo Night:

systemctl --user status omarchy-org-theme-server
curl -v http://127.0.0.1:17823/theme.css 2>&1 | head
ls ~/.config/omarchy/hooks/theme-set.d/99-omarchy-org-sync.sh
~/.local/bin/omarchy-org-theme-build && curl -s http://127.0.0.1:17823/theme.css | head

Violentmonkey → script → ensure checkmark is on, Tampermonkey → Details → @connect 127.0.0.1 allowed. Reload omarchy.org with Ctrl+Shift+R.

Port 17823 taken: ss -tlnp | grep 17823 → edit PORT in both server + userscript (URL_CSS).

Light theme unreadable: ensure theme.css has color-scheme: light near top — rebuild.

uninstall
# stop server + remove bridge
systemctl --user disable --now omarchy-org-theme-server.service
rm ~/.config/systemd/user/omarchy-org-theme-server.service
rm ~/.config/omarchy/hooks/theme-set.d/99-omarchy-org-sync.sh
rm ~/.local/bin/omarchy-org-theme-build ~/.local/bin/omarchy-org-theme-server
systemctl --user daemon-reload
rm -rf ~/.cache/omarchy-org
# browser: Violentmonkey → remove omarchy.org script

Omarchy themes themselves untouched. omarchy theme set keeps working.
